# 本地 AI 简历档案库

面向时空视点人事团队的本地简历管理工具，集中保存 PDF 原件、解析结果和上传记录，便于按候选人信息或简历正文检索。

## 功能

- **批量导入**：多选或拖拽上传 PDF，单份最多 20 MB、30 页。任务在后台处理，失败后可单独重试。
- **解析归档**：直接提取 PDF 文本，对文字不足的页面使用本地中英文 OCR。支持通过兼容 Chat Completions 的模型提取结构化字段，未配置密钥时使用本地规则。
- **检索预览**：按姓名、岗位、公司、技能等字段搜索，支持学历和公司筛选，以及可选的全文搜索。详情页可查看解析结果、原文和逐页预览。
- **本地存储**：SQLite 保存档案和任务，原始 PDF 保存在 `data/uploads/`。相同文件自动去重。

## 快速开始

双击 `启动.cmd`。退出时运行 `停止.cmd`。

**从源码运行**：需要 Node.js 24.14 或更高的 24.x 版本。在仓库根目录执行：

```bash
npm ci
npm start
```

默认访问 <http://127.0.0.1:3000>。本地模式仅监听回环地址。

## 模型配置与数据

在「模型设置」中填写 Base URL、API Key 和模型名称。配置外部模型后，提取出的简历文本会发送给该服务。接口配置示例见 [`.env.example`](.env.example)。

备份或迁移时，先停止服务，再复制整个 `data/` 目录。真实简历、数据库和 `.env` 请保留在本地。

## 开发

技术栈为 Node.js、Express、原生 JavaScript 和 SQLite。`src/` 存放服务端代码，`public/` 存放前端，`migrations/` 管理数据库迁移。

```bash
npm run format:check
npm run check
npm test
npm run test:ocr
```
